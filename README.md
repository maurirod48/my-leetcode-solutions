## Mindset Notes

Things I remind myself of constantly:

- **Understand before you code.** Talk through the problem out loud first.
- **Brute force is a valid first step.** Get it working, then optimize.
- **Always state time and space complexity.** Every. Single. Time.
- **If you're stuck after 20-25 min, look at the pattern hint — not the answer.**
- **Re-solve problems you struggled with.** A week later, try again from scratch.
